# Reelio brand clearance

Type: task
Status: resolved
Map: [Reelio MVP](../map.md)

## Question

Can "Reelio" be used publicly without unacceptable trademark or naming risk, and is a suitable domain available?

This is HITL: the human runs trademark searches in the relevant jurisdictions and checks domain availability. The agent provides the checklist. It does not block the spec, because "Reelio" remains a working name until this is resolved.

## Answer

**"Reelio" is not cleared. Decided: drop it** and choose a replacement in [Product name](./20-product-name.md). "Reelio" stays the working name in code and the spec until then.

What the check found (2026-11-04, web search and `whois`/`dig`, not a legal opinion):

- **Disqualifying conflict:** an iOS app "Reelio: Movie & TV Watchlist" (App Store id 6789773022), seen via a third-party listing (<https://chrome-stats.com/d/id6789773022>). It's a movie and TV watchlist built on TMDB, with a paid premium tier, version 1.0, updated 2026-07-23. Same name, same goods, same data source, earlier use: a real risk of confusion and of a prior-use claim, whatever the registers say.
- **Other uses in unrelated fields:** a Shopify shoppable-video app, an AI video generator, and a Product Hunt listing.
- **USPTO:** the only exact REELIO filing found, Serial No. 90907528 (Class 9, 2021), is listed as dead (via markinton.com; not confirmed in TSDR). There are similar live marks (RELIO). EUIPO and the UK IPO were not searched.
- **Domains:** taken: `reelio.com` (2012), `reelio.io` (2022), `reelio.co` (2024), `reelio.tv` (2025), `getreelio.com` (2026-07-14). `reelio.app` is probably taken (GoDaddy nameservers). `reelio.film` and `reelio.movie` show no registry record.
